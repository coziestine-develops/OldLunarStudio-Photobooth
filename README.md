# 📸 OldLunar Studio – Photobooth

> **Capture the moment. Keep the memory. 🌙**

OldLunar Studio – Photobooth is a modern and interactive photobooth web application designed to make taking, customizing, and saving photos simple and fun.

## ✨ Features

* 📷 **Photo Capture** – Take photos directly through the camera.
* 🖼️ **Photobooth Layouts** – Choose from different photo layouts and frames.
* 🎨 **Photo Customization** – Add creative designs and effects.
* ⏱️ **Countdown Timer** – Prepare for each shot with a countdown.
* 📸 **Multiple Shots** – Capture multiple photos for a photobooth strip.
* 💾 **Save Photos** – Download the finished photobooth image.
* 📱 **Responsive Design** – Works across desktop, tablet, and mobile devices.
* 🌙 **Modern Studio Aesthetic** – Clean and visually appealing interface.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/coziestine-develops/oldluna-photobooth.git
```

### 2. Navigate to the project

```bash
cd oldluna-photobooth
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will usually be available at:

```text
http://localhost:5173
```

## 📦 Build for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## 🔐 Camera Permissions

The photobooth requires access to the user's camera.

When prompted by the browser, select **Allow** to enable photo capture.

For production deployment, camera access should be served over **HTTPS**.
